# Vanilla ships three difficulty modes, so we ship three

**RULED (Nicolas): "Vanilla ships three difficulty modes then so should we."** The FE-strictness
principle applied where it has always pointed — FE8 is the spine, and where vanilla has an
answer we take it rather than inventing a smaller game.

This closes a question that had never been ASKED, which is why it is worth an entry rather than
a checkbox: the difficulty select screen has been live since ch01 (New Game passes through
`ProcScr_NewGameDifficultySelect`), so a player could always pick Difficult. What they got was
never chosen by us.
