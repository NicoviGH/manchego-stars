# Sources for the FE8 per-chapter deploy research

Research compiled 2026-10-27 from web walkthroughs. Normal mode unless stated. Every claim carries a
source tag; the tags resolve to URLs in the table below. Where a fact comes from one source only, it is
marked "(single source)". Where sources disagree, a **CONTESTED** line says so.

Caveat on method: most pages were read through an extraction model (WebFetch / Firecrawl "query"),
not line by line. Quoted phrases are from those extractions. A few extraction artefacts were caught and
are flagged inline ("extraction unclear").
