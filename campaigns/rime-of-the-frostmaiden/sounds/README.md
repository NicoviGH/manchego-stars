# Campaign sound effects

One-shot samples appended to FE8's song table by `tools/inject/sounds.py` (ADR 0333). Each is a
mono 8-bit AIFF made with `tools/wav_to_aif.py`.

| File | Used for | Source |
|---|---|---|
| `ms_kyogre_cry.aif` | ch06: Messie surfaces (`SONG_MS_KYOGRE_CRY`) | Kyogre's cry, Pokemon Ruby/Sapphire/Emerald (Game Freak), from `pret/pokeemerald` `sound/direct_sound_samples/cries/kyogre.wav` |
