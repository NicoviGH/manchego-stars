# Lupin (mdg_at1-flavour) Sword/Lance — imported wolf pounce (#90 pipeline, per-character _u25).
# Frames: 000 idle · 001 windup(coil) · 002 lunge(airborne) · 003 hit(jaws on the foe) · 004 dodge.
# The attack is a POUNCE: coil -> leave the ground -> land the bite ON the foe -> push off and
# settle home. Frame position on the shared canvas IS the motion (see poses.yaml).
#
# CADENCE + SOUND are read off FE8's OWN WOLF, `banim_mdg_at1` (CLASS_MAUTHEDOOG, banim 0xB0 —
# the anim the rest of Lupin's pack fights as), not invented and not copied from the Cavalier
# donor: a horse's gallop-and-thrust is the wrong rhythm for a beast that leaps. From it:
#   * C5A `sound_mauthedoog_1` opens the attack, C5B `..._2` fires just before contact, and
#     C5D `..._3` twice on the recovery. Lupin therefore SOUNDS like his own pack.
#   * C20 `sound_hit_eliwood_promoted_durandal` is the impact SFX vanilla pairs with the bite.
#   * `prepare_hp_deplete` (C04) sits BEFORE the hit and `wait_hp_deplete` (C01) after it.
#   * `attack_miss` is the attack body with ONLY the hit code + impact SFX removed — C04 and C01
#     stay. Dropping C04 there is what soft-locked ch04 on turn 4 (#24 / decisions.md).
# Vanilla's run-up alternates two frames a dozen times because it HAS a run cycle; we have one
# airborne pose, so the weight goes into a LINGER on the coil instead ("linger like vanilla" —
# the Pinky lesson). Durations tuned on the recordanim review.
# When importing to FEditorAdv delete # and after each line.
